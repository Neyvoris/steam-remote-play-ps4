# Steam Remote Play PS4

Неофициальный клиент Steam Remote Play для PlayStation 4. Цель проекта — передавать видео и звук с компьютера, на котором запущен Steam, и отправлять обратно ввод с контроллера PS4.

## Статус

Репозиторий подготовлен к импорту исходников. Сборок и инструкций по установке пока нет.

## Следующий шаг

Импортировать исходники проекта с информацией об их лицензиях, затем описать зависимости и шаги сборки. Журналы, данные авторизации и проприетарные файлы Steam хранятся отдельно.
